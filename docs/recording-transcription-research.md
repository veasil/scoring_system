# 录音转录技术调研报告

> 场景：多人桌游（4-8人，含儿童2-18岁），需清晰采集并转录为文字
> 调研日期：2026-05-17

---

## 一、核心挑战

| 挑战 | 说明 |
|------|------|
| 多人同时说话 | 桌游中多人抢话、同时反应常见 |
| 儿童声音 | 音调高、吐字不清、语速不稳定 |
| 环境噪音 | 社区活动室/家庭，桌椅碰撞、笑声 |
| 说话人识别 | 需区分谁说了什么（辅助复盘） |
| 方言/口音 | 儿童可能带方言 |

### 详细分析

#### 讯飞（推荐首选）
- **优势**：中文识别业界最强，儿童语音适配好（有教育场景数据），说话人分离成熟
- **产品选择**：
  - "录音文件转写" — 上传音频文件，离线转写，~3.5元/小时，支持说话人分离
  - "实时语音转写" — WebSocket 流式，~26元/小时，延迟<2秒
- **接入**：REST API / WebSocket，SDK 支持 Node.js
- **注意**：免费额度有限（新注册500次/年）

#### 阿里云智能语音
- **优势**：已有阿里云OSS账号（生态兼容），定价略低
- **产品选择**：
  - "录音文件识别" — ~3元/小时
  - "实时语音识别" — ~18元/小时
- **说话人分离**：需开通"声纹识别"服务，额外计费
- **接入**：与现有OSS SDK同一体系

#### Whisper (OpenAI)
- **优势**：多语言、开源可自建、无需注册国内服务
- **劣势**：
  - 中文准确率不如国产方案
  - 不支持原生说话人分离（需 pyannote.audio 等额外模型）
  - 自建需 GPU (NVIDIA T4/A10, ~16GB VRAM)
  - 延迟较高，不适合实时
- **适合**：预算有限 + 对准确率要求不极高 + 有GPU资源

## 四、端侧/混合方案

| 方案 | 描述 | 优劣 |
|------|------|------|
| 讯飞 SR502 + 讯飞开放平台 | 录音笔录制 → 上传云端转写 | 成本最低，但说话人分离上限4人 |
| 讯飞听见 M2 + 讯飞云转写 | 麦克风阵列录制 → 自动上传转写 | 最佳体验，一体化流程 |
| 本地 Whisper + pyannote | GPU服务器部署 | 无API费用，但需维护，中文效果一般 |

## 五、推荐方案

### 方案 A：最佳效果（预算~3000元/月）
- **硬件**：讯飞听见 M2（一次性 ~1500元）
- **转写**：讯飞录音文件转写 API（~3.5元/小时）
- **流程**：录制 → M2自动上传 → 讯飞转写（含说话人分离） → 回调写入系统
- **月成本估算**：假设每月20场×1小时 = 70元/月 API费用

### 方案 B：低成本入门（预算~1000元）
- **硬件**：讯飞 SR502 录音笔（~800元）
- **转写**：阿里云录音文件识别（~3元/小时，复用现有阿里云账号）
- **流程**：SR502录制 → 手动上传 → 阿里云转写 → 下载结果
- **月成本估算**：~60元/月

### 方案 C：未来全自动（预算较高）
- **硬件**：讯飞听见 M2
- **转写**：讯飞实时语音转写（~26元/小时）
- **流程**：实时录制 + 实时转录 → 直接显示在桌游主持界面
- **月成本估算**：~520元/月
- **适合**：#11 引导+计分系统合并后的主持人工作台

---

## 六、关键建议

1. **先用方案 A 跑通**：讯飞听见 M2 + 录音文件转写，一次性投入1500元+每月70元
2. **确认预算后升级**：若需实时转录再切到方案 C
3. **集成路径**：
   - 后端新增 `/api/admin/transcription` 端点
   - 调用讯飞录音文件转写 API（WebSocket/HTTP回调）
   - 结果存入 `game_sessions.transcription_json` 字段
4. **儿童语音优化**：讯飞支持"热词"功能，可上传桌游专业词汇（如"安全力"、"脑波力"等）作为优先识别词

## 七、待确认事项

| 问题 | 影响决策 |
|------|----------|
| 每场桌游几人？ | 4人以下可用SR502，4人以上需M2 |
| 是否需要实时转录？ | 影响API选择和成本（3x差价） |
| 月预算上限？ | 决定用录音转写还是实时转写 |
| 是否需要保存原始音频？ | 影响存储成本（OSS ~0.12元/GB/月） |
